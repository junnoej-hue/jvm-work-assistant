# 검증 기록 · v0.2.0 · 2026-10-15

- Python 3.12 / macOS에서 38개 자동 테스트 통과. 기존 29개 검사에 개인 기록 저장·읽기·수정본 보존·재시도 중복 방지·권한·경로 이탈/심볼릭 링크 거부·파일 변조 탐지·목록 제한 9개를 추가했습니다.
- 실제 MCP stdio에서 도구 9개와 6회 호출 확인. 개인 기록 저장 후 같은 파일을 다시 읽었습니다. 개인 기록 쓰기는 로컬 전용이며 메일/Webex 도구는 여전히 읽기 전용입니다.
- 설치된 0.2.0 모듈과 pip check 확인. 테스트에는 합성 자료와 임시 작업 폴더만 사용했으며 실제 인증정보·메일·채팅을 사용하지 않았습니다.
- 개인 기록/팀 요약 분리를 안내하는 업무 스킬·설치/업데이트 안내를 갱신했습니다. 다른 팀원 Mac의 실제 계정 연결과 AI별 지침 준수는 별도 확인해야 합니다. 이 지침이 Notion 권한을 기술적으로 제한하지는 않습니다.

아래는 0.1.0 당시의 검증 이력입니다. Keychain·깨끗한 설치 등 이전 결과를 이번 버전에서 새로 수행했다고 주장하지 않습니다.

## 아직 검증하지 않은 것

- 이 새 패키지에서 실제 Zimbra 로그인·메일 조회 및 Webex OAuth 첫 로그인·메시지 조회. 기존 개인 브리지의 비밀값은 이식하지 않았습니다.
- 각 팀원의 Mac, Intel Mac, Python 3.11/기타 버전, 각 AI 앱 UI에서의 실제 설치/도구 노출.
- Notion 생성/수정 end-to-end, 템플릿 생성 결과·버튼 실행·진행률 재계산.
- 기업별 IMAP/OAuth 정책·관리자 승인. 이 조건은 코드 설치로 해결되지 않습니다.

따라서 배포 첫 사용자는 docs/SETUP.md대로 자기 계정을 연결하고 `doctor --live` 및 작은 실무 요청을 확인해야 합니다. 프로그램 설치와 서비스 연결 성공을 혼동하지 않습니다.
